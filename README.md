# yifanyuan.com · 袁一帆个人主页

纯静态网站（HTML + CSS + 少量 JS），无需构建，中英文双语，可直接部署到 GitHub Pages。

## 文件结构

```
index.html            主页（页面框架；里面的内容由 data/ 生成）
data/home.json        个人信息、简介、研究方向、经历、科研项目、学术服务、页脚
data/news.json        最新动态
data/publications.json 论文
data/lab.json         实验室网站独有的内容：代表作、最新动态、栏目说明、简介、MUSE 释义、负责人卡片上的链接、研究方向、联系方式
admin/                登录页（index.html）和网页编辑器（editor.js、render.js 等）
404.html              404 页面
CNAME                 自定义域名 yifanyuan.com（GitHub Pages 用）
.nojekyll             告诉 GitHub Pages 不要用 Jekyll 处理
robots.txt / sitemap.xml
assets/css/style.css  样式
assets/js/main.js     语言切换、论文列表切换、手机菜单
assets/fonts/         标题字体（已内置，国内访问不依赖 Google Fonts）
images/yifan-yuan.jpg 个人照片（原图尺寸，无边框）
images/muse-logo.png  MUSE Lab 图标（原版 logo 去背景，只保留 M 图形）
images/papers/        论文配图（各论文 PDF 中的框架图；后台上传的配图也放在这里）
images/logos/         深大、复旦校徽，腾讯、商汤徽标
images/work/          实验室代表作卡片上的动画配图（SVG，源文件 tools/work_visuals/make_visuals.py）
lab/                  MUSE Lab 实验室网站：index.html（页面框架，内容由 data/ 生成）、lab.css（样式）、lab.js（交互）
lab/projects/<地址>/  每个代表作的项目页（整页由 data/ 生成，不要手动改）
```

## 本地预览

直接双击 `index.html` 即可在浏览器里打开。

## 在网页上直接修改内容

网站上线后打开 `https://yifanyuan.com/admin/`，用 GitHub 令牌登录（登录页有三步说明），可以选择编辑个人主页或实验室网站。以后在这台设备上打开主页或实验室网站，左下角会出现“✎ 编辑页面”按钮，访客看不到它。下面先说主页，实验室网站的编辑见“实验室网站”一节。

- **文字**：点一下就能在原位置修改，个人简介、姓名、职位、签名、标语、栏目标题、研究方向、实验室介绍、动态和论文里的文字都可以。选中文字后可以加粗、加链接；Enter 完成，Esc 取消。
- **中英文**：改的是当前显示的语言；点底部的“中文 / EN”切换后，再改另一种语言。
- **照片**：点照片换一张，会自动压缩。
- **列表**：联系方式、简介段落、动态、论文、经历、科研项目、此前的项目、学术服务、页脚链接。
  - 栏目标题右边的“＋ 添加…”用来新增。
  - 鼠标移到某一条上，右上角会出现“编辑 / ↑ / ↓ / 删除”。“编辑”打开右侧面板，所有字段（中英文、日期、图标、链接、Logo 等）都在里面，左边的页面会跟着实时变化。
- **论文**：
  - 在面板里粘贴 arXiv 链接或 DOI，会自动填好标题、作者和链接；也可以上传 PDF。
  - 选一张研究方向卡片，会自动生成标签。
  - 打开“代表性论文”后上传框架图（自动压缩到 1400 像素宽），再写中英文简介。
  - 新增论文后，可以一键写一条对应的动态。
- **研究方向卡片**：标题、介绍、印章字都能改。卡片底部的论文标签在对应论文的面板里设置。
- **Google Scholar 等链接**：在侧栏点“＋ 添加联系方式”，图标选 Google Scholar。
- **底部编辑栏**：撤销、预览（隐藏编辑标记，看最终效果）、放弃修改、**发布到网站**、退出。发布时所有修改合成一次提交，约 1 分钟后网站更新，页脚的“最后更新”会自动改成当月。
- **修改记录和冲突**：每次发布都记录在 GitHub 仓库的提交历史里，改错了可以在 GitHub 上恢复。如果在另一台设备上发布过，编辑器会提示先重新载入，不会覆盖那边的修改。
- **实验室网站同步更新**：实验室网站上的动态、研究方向和论文与主页用的是同一份数据，在主页编辑器里发布时，`lab/index.html` 会在同一次提交里一起更新。动态面板里有“也显示在实验室网站上”的开关，个人经历类的动态（比如博士毕业）可以关掉。
- **令牌**：只保存在自己设备的浏览器里，有效期一年，过期后照登录页的步骤重新生成。登录页不会被搜索引擎收录。

编辑器改的是 `data/` 里的三个 JSON 文件，并据此重新生成 `index.html` 和 `lab/index.html` 里的内容（在 `<!-- 名称:start -->` 和 `<!-- 名称:end -->` 标记之间，这部分不要手动改）。想跳过编辑器、直接改 JSON 时，改完在项目文件夹运行 `node tools/render_site.js` 重新生成两个页面和实验室的项目页（`--check` 只检查是否最新）。

## 实验室网站（lab/）

地址 `https://yifanyuan.com/lab/`，版式参考 Google DeepMind 的网站，配色、字体沿用原来的水彩风格。从上到下：

- 首屏：右上角是实验室 logo；五线谱、音符、水彩画笔的互动背景；“MUSE Lab”下面依次是全称、标语、两个按钮、方向标签和滚动播放的动态（一次两行）。标题离顶栏留了一段空，屏幕矮时标题会自动缩小一些，保证首屏放得下。
- 01 实验室简介：MUSE Lab 全称与含义，负责人卡片和 MUSE 四个字母的释义。
- 02 研究方向：五张卡片排成一排，可以左右滑动（绘 图像视频生成与编辑、懂 多模态理解与应用、信 可信大模型与智能体、情 情感智能、机 具身智能），每张有一句话简介、课题标签和代表工作，方向的插画淡淡地铺在卡片背景上。
- 03 代表作：一排高卡片，同样可以左右滑动。每张卡片有论文简称、通俗介绍、一张说明它在做什么的动画配图、“了解更多”和代码链接。
- 04 最新动态：两列标题，每条一句让人一眼看懂的话，下面是日期、类别和“了解更多”，右边一张方形配图；点整条都能打开。
- 05 论文成果：全部论文按年份排列、可按研究方向筛选（代表作已在上面单独展示）。
- 06 科研项目：主页“科研项目”里的项目，每个有角色、起止时间、项目名称、一句话介绍和项目来源。
- 07 联系我们：负责人、地址、邮箱、代码。

两排卡片在电脑上可以点栏目标题右边的箭头，或按住鼠标拖动；手机上直接滑动。栏目标题下面不放说明文字。

每个代表作有一个项目页（`lab/projects/<地址>/`，统一模板）：论文简称和题目、通俗介绍、作者、Paper / Code / BibTeX 按钮和动画配图，下面是概览（论文简介）、要点、方法（框架图）、可一键复制的引用，最后是其他代表作。

- **在网页上直接修改**：和主页一样，登录后在实验室网站点左下角的“✎ 编辑页面”（或打开 `https://yifanyuan.com/lab/?edit`）。
  - 点文字就能在原位置修改：首屏标语（选中文字可以“高亮”）、栏目标题、代表作卡片的介绍、最新动态的标题和类别、实验室简介、MUSE 释义、研究方向的印章字 / 标题 / 简介 / 课题标签、联系我们上方的一句话和每条联系方式。
  - 列表：研究方向、代表作、最新动态、首屏标签、简介段落、负责人卡片上的链接、联系方式，都有“＋ 添加…”和“编辑 / ↑ / ↓ / 删除”。
  - **研究方向**：一排卡片最后的“＋ 添加研究方向”。面板里填印章字、卡片颜色（雾蓝、灰绿、浅粉、淡紫、钢灰、沙橙、薄荷绿、杏色）、中英文标题和一句话简介、课题标签（每行一个）、背景插画（自动压缩到 1200 像素宽）和图片说明，再从论文列表里勾选代表工作。
  - **代表作**：一排卡片最后的“＋ 添加代表作”。面板里选对应的论文（题目、作者、链接、概览和框架图都从论文取，论文在主页编辑），写介绍（中英文）、项目页要点（每行一条），选卡片颜色，可以上传配图（PNG 或 JPG，自动压缩到 720 像素宽）；“高级”里可以改项目页地址，留空按论文简称自动生成。卡片的先后就是页面上的顺序，用 ↑ / ↓ 调整。
  - **最新动态**：列表上方的“＋ 添加一条最新动态”。填日期、类别、一句话标题，选点开后进入哪个代表作，或者填一个链接；配图可选，进入代表作时默认用代表作的配图。保存后按日期从新到旧排列。
  - 首屏滚动的动态、论文和科研项目与主页共用，仍在主页的编辑模式里改（编辑模式下页面上有提示）。科研项目的面板里有“一句话介绍”（显示在实验室网站上）和“也显示在实验室网站上”的开关。
  - 发布时一次提交 `data/lab.json`、`lab/index.html`、内容有变化的项目页和新图片，用的是网站上最新的动态和论文；在别处改过实验室内容时会提示先重新载入，不会覆盖。在主页编辑器里改了论文，项目页也会在同一次提交里更新。
- 首屏动态和论文：和主页共用数据，在主页编辑器里改，发布时自动同步。首屏的动态一次三行（手机上两行），鼠标移上去会停，每条前面的图标和主页相同。
- 负责人的姓名、职位和照片用的是主页 `data/home.json` 里的个人信息。
- 其余内容都在 `data/lab.json`（不想用编辑器时，直接改它再运行 `node tools/render_site.js`，项目页会一起生成）：
  - `hero` 首屏的标语 `tagline`（`==可信==` 这样包起来的字会有荧光笔效果）和标签 `topics`；`headings` 各栏目标题。
  - `projects` 代表作（按页面上的顺序）：`paper` 论文编号（`data/publications.json` 里的 `id`）、`slug` 项目页地址、`tone` 卡片颜色（同下面研究方向的颜色）、`visual` 配图、`blurb` 介绍、`points` 项目页要点。
  - `stories` 最新动态：`date`、`tag` 类别、`title` 一句话标题、`project` 点开后进入的代表作（填它的 `slug`），或者 `url` 链接；`image` 配图可选。
  - `about` 简介段落；`acronym` MUSE 释义；`pi.links` 负责人卡片上的链接。
  - `directions` 研究方向：`seal` 印章字、`tone` 卡片颜色（`blue` `green` `pink` `lavender` `steel` `sand` `mint` `peach`）、`title` 标题、`summary` 一句话简介、`topics` 课题标签、`papers` 代表工作（填论文编号，建议不超过 4 篇）、`cover` 卡片的背景插画（只用第一张：`src` 图片路径、`alt` 英文图片说明，可选 `position` 裁切时保留的位置、`credit` 别人图片的作者与许可，会列在页脚“图片来源”里）。绘、信两个方向与个人主页对应，配色也相同。
- 科研项目在主页的 `data/home.json` 里（`grants`）：每项的 `brief` 是实验室网站上的一句话介绍，`lab: false` 可以让某一项不在实验室网站显示。
  - `contactIntro` 联系我们上方的一句话；`contact` 联系方式（按列出的顺序，两列排列）。
- 代表作的五张动画配图是代码画的 SVG（每个元素按时间轴出现、循环播放；系统开启“减少动态效果”时直接显示完整画面），源文件 `tools/work_visuals/make_visuals.py`，运行后写到 `images/work/`。
- 研究方向的插画也是用代码画的，源文件在 `tools/research_covers/covers.html`：改完用同一文件夹的 `render_covers.py` 导出 PNG、`to_webp.py` 转成 `dir-<方向>.webp`，放进 `images/`。
- 栏目标题、研究方向标题和印章字用毛笔字体显示，新增的字要重新生成字体子集：`python tools/build_fonts.py <Inter/Fraunces 源文件夹> <马善政字体文件夹> site --brush-only`（会扫描主页、实验室网站和项目页；最新动态的中文标题用普通黑体，不占字体）。
- 声音：音符跳起、拨动五线谱时发出柔和的音符声（五声音阶，越靠上音越高）；点击首屏会奏出一段原创的慢速旋律（降 E 大调，约 76 拍每分钟、7 秒左右：柔和的电钢琴先上行琶音再回落，最后停在一个温暖的和弦上，下面垫着很轻的和声），再点一次会让上一段渐弱后重新开始。旋律在 `lab/lab.js` 的 `MELODY`（音符）和 `HARMONY`（和弦）里，音高按距中央 C 的半音数写。浏览器要求先点一下页面才允许出声；右上角的喇叭按钮可以静音，选择会被记住。

## 编辑器以外的部分

下面这些直接改文件：

- 顶部导航文字、语言按钮、MUSE Lab 卡片的图形和按钮：`index.html` 里标记之外的部分。中英文成对出现（`<span class="en">…</span><span class="zh">…</span>`），两份都要改。
- 网页标题和搜索引擎描述：`index.html` 的 `<head>`。
- 研究方向卡片的配色：CSS 的 `.theme-card--visual / --trust / --affect`（实验室网站卡片的几种颜色是 `lab/lab.css` 里的 `.tone-blue / -green / -pink / -lavender / -steel / -sand / -mint / -peach`，前三种和主页相同）。
- 经历里的单位徽标统一放在白色小方块里（`.experience-logo`），新徽标用透明背景的方形 PNG 即可。
- 实验室网站的导航、“MUSE Lab”标题、全称和首屏的两个按钮：`lab/index.html` 里标记之外的部分。

访问 `https://yifanyuan.com/?lang=zh` 或 `?lang=en` 可以直接打开指定语言；不带参数时按访客浏览器语言自动选择，访客手动切换后会被记住。

## 配色与动效

- 配色取自照片背景的灰蓝色 `#9ea8be`，在 `assets/css/style.css` 顶部的 `:root` 里统一修改（`--accent` 是链接色，`--photo` 是照片原色）。
- MUSE Lab 卡片和会议名标签用 logo 的藏青 `--muse-navy`、天蓝 `--muse-sky`、橙色 `--muse-orange`；研究方向三张卡片用低饱和的雾蓝（视觉）、灰绿（可信）、浅粉（情感）。
- 个人主页动效：内容随滚动渐次浮现、研究方向的书法印章“盖章”出现、卡片悬停上浮与配图放大、卡片跟随鼠标的柔光、照片随鼠标轻微倾斜、MUSE Lab 卡片的水彩与音符漂浮、标语关键词的荧光笔划出、点击论文标签跳转并高亮、顶部阅读进度条、回到顶部按钮。
- 实验室网站首屏：标题“MUSE”有缓慢流动的光泽；页面载入时一支水彩笔在标题后面写出一个柔和的“M”，结尾拖出一道渐细的弧线；鼠标移动留下彩色水彩笔触（笔迹会顺滑成弧线），划过五线谱会拨动琴弦并弹出音符，靠近音符会让它跳起来，点击会溅出颜料和一串音符，同时奏出一段舒缓的旋律；没人操作时会有“隐形画笔”自己作画；最新动态每隔几秒向上滚动一条。首屏滚出屏幕后画面动画自动暂停。
- 实验室网站其他部分：内容随滚动渐次浮现（和个人主页一样，每张卡片、每条动态、每条论文和联系方式依次浮上来，一排卡片里滑进屏幕的那张才出现）、研究方向印章“盖章”、卡片背景插画在悬停时变清楚并轻微放大、代表作配图的动画、卡片悬停上浮与跟随鼠标的柔光、栏目标题下水彩笔触划出、论文按方向筛选、顶部导航随滚动变成磨砂玻璃并标出当前栏目。
- 系统开启“减少动态效果”时，所有动画和声音自动关闭，内容直接显示。

## 部署到 GitHub Pages（绑定 yifanyuan.com）

1. 登录 GitHub，新建一个 **Public** 仓库（名字随意，例如 `homepage`）。
2. 进入仓库，`Add file → Upload files`，把本文件夹里的**全部内容**拖进去（包括 `CNAME` 和 `.nojekyll`），点 `Commit changes`。
3. `Settings → Pages`：Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 同一页的 `Custom domain` 填 `yifanyuan.com` 并保存（仓库里已有 CNAME 文件，通常会自动填好）。
5. 到购买域名的平台（阿里云 / 腾讯云 / Namecheap 等）的 DNS 解析里添加记录，并删除冲突的默认记录（如停放页、URL 转发）：

   | 主机记录 | 类型 | 记录值 |
   |---|---|---|
   | `@` | A | `185.199.108.153` |
   | `@` | A | `185.199.109.153` |
   | `@` | A | `185.199.110.153` |
   | `@` | A | `185.199.111.153` |
   | `www` | CNAME | `你的GitHub用户名.github.io` |

   （可选 IPv6：`@` 的 AAAA 记录 `2606:50c0:8000::153`、`2606:50c0:8001::153`、`2606:50c0:8002::153`、`2606:50c0:8003::153`）

6. 解析生效后（几分钟到几小时），回到 `Settings → Pages`，勾选 **Enforce HTTPS**。
7. 建议在 GitHub 账号 `Settings → Pages → Add a domain` 里验证域名，防止被他人占用。
8. （可选）在 `admin/config.js` 里把 `repo` 填成 `你的GitHub用户名/仓库名`，登录页就会自动填好仓库。

以后改内容：在主页的编辑模式里改；编辑器以外的部分在 GitHub 网页上直接编辑文件并提交。两种方式都是约 1 分钟后网站自动更新。

> GitHub Pages 服务器在境外，使用自己的域名**不需要 ICP 备案**。若以后想换到阿里云 OSS、腾讯云 COS 等国内服务器以提升国内访问速度，绑定自定义域名需要先完成备案。
